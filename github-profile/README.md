### About me

I study **computer science**, with an interest in **LLM interpretability, data science, computational social science**, and building interfaces that make complex information intuitive.

My recent research explores **reasoning dynamics in large language models**, including hidden states, attractor-like behaviors, and activation steering. Beyond research, I enjoy creating practical tools, interactive visualizations, and experimental apps.
